# uuu Studio v3 — эталон обучающего видео

Это не «PDF → слайды → зачитать текст». Это педагогический монтаж: **вопрос → время подумать → пошаговое решение → проверка**. Полная русская версия Math I (недели 1–4) рассчитана на **195 минут**, при этом длительность достигается не повторами, а активной работой зрителя.

Локальному ИИ-агенту сначала прочитать [`AGENTS.md`](AGENTS.md): там источники истины, обязательный цикл и definition of done.

## Что улучшено относительно v2

- 4 авторские анимированные сцены: корни на комплексной плоскости, композиция функций, теорема о двух милиционерах, символы Ландау.
- Вопрос показывается **до** решения; таймер не требует озвучки и не мешает поставить видео на паузу.
- Повторные задания ISA превращены в короткие проверки с ответом, а не в повторный разбор.
- Проверка запрещает дословные повторы озвучки, неизвестные сцены, битый KaTeX, сырые PDF-степени, пустые вопросы без выражений и типичные фразы-наполнители.
- Аудированные OCR/математические исправления вынесены в генератор: комплексные степени, области определения, устранимый разрыв, логарифмические уравнения и модели роста подкреплены численными regression assertions.
- Реальные субтитры по времени каждой фразы и главы в MP4, а не восьмисекундные заголовки вместо SRT.
- Нормализация громкости до −16 LUFS; основной русский голос Svetlana, Dmitry — резервный. У каждого сегмента 8 попыток и жёсткий таймаут 75 секунд.
- Все этапы возобновляемы. Изменение спека автоматически инвалидирует устаревшие аудио, кадры и тайминги.
- Нет покадровой подсветки каждого слова: v2 из-за неё почти не использовал статические кадры. В v3 снимаются только реальные изменения геометрии.
- Все ресурсы локальные: KaTeX и шрифты не зависят от CDN. Любой кадр является чистой функцией `window.__seek(t)`.

## Локальный запуск

```bash
python3 -m pip install playwright edge-tts pillow numpy pymupdf
python3 -m playwright install chromium --with-deps
# ffmpeg должен быть в PATH

python3 video-pipeline-v3/make_math_masterclass.py
python3 video-pipeline-v3/validate_spec.py \
  video-pipeline-v3/content/math1_w14_ru.json

python3 video-pipeline-v3/make_preview.py
python3 video-pipeline-v3/render_video.py \
  --spec video-pipeline-v3/content/math1_w14_v3_preview.json \
  --out video-pipeline-v3/out/preview \
  --workdir video-pipeline-v3/work/preview --workers 2
```

Полный рендер:

```bash
python3 video-pipeline-v3/render_video.py \
  --spec video-pipeline-v3/content/math1_w14_ru.json \
  --out video-pipeline-v3/out/full \
  --workdir video-pipeline-v3/work/full --workers 3
```

Повторная команда продолжит с готовых сегментов. `--tts-only`, `--skip-tts`, `--plan-only` доступны для отдельных стадий.


Kaggle-токен не хранится в репозитории, kernel metadata или dataset. Приватный kernel: [`freedomform/math1-w14-ru-v3`](https://www.kaggle.com/code/freedomform/math1-w14-ru-v3). Интернет нужен для Edge TTS и установки Chromium. Полный запуск сначала синтезирует речь, затем добавляет паузы для самостоятельного решения и рендерит оставшееся время; готовые MP4/SRT скачиваются последней командой выше.

## Как писать хороший спек

1. **Одна сцена — одна мысль.** Не помещайте весь параграф PDF на карточку.
2. **Сначала вопрос.** Для новой задачи добавьте `question` с тем же условием. `hold` — минимальная пауза; `flex: true` разрешает увеличить её для целевой длительности.
3. **Озвучка объясняет причину, экран показывает действие.** Не читайте вслух длинный список, который зритель и так видит.
4. **Математику нужно увидеть.** Если есть геометрический смысл, используйте `plot` или добавьте отдельный `visual` builder. Не заменяйте график словами «представьте график».
5. **Повтор — новая активность.** Повторную задачу делайте быстрой проверкой, а не вторым одинаковым объяснением.
6. **Никакой воды.** «В современном мире», «как мы уже говорили», «это легко» не несут информации. Валидатор помечает такие фразы.
7. **Проверка ответа обязательна.** Подстановка, оценка порядка, график или альтернативный метод — не просто «ответ получен».
8. **Пауза — учебный элемент.** Не замедляйте голос и не добавляйте текст ради хронометража.

### Минимальный пример

```json
{
  "type": "question",
  "data": {
    "heading": "Сначала — самостоятельно",
    "problem": "Найдите все решения $z^3=-8$.",
    "hold": 12,
    "flex": true
  },
  "narr": [],
  "narr_item": []
}
```

После него идёт `example` с короткими `steps`, `result` и причинной озвучкой. Каждый элемент `narr_item` соответствует сегменту `narr`; `-1` означает общую реплику, `0, 1, …` — раскрытие конкретного шага.

## QA результата

`*.report.json` проверяет видео- и аудиопотоки, ширину 1920, хронометраж и восемь кадров на пустоту. `comp/stills/` содержит контрольные кадры. Перед публикацией дополнительно посмотрите пробный MP4 целиком: автоматика не оценивает педагогику и вкус.
