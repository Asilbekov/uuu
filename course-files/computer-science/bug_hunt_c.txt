PROBLEM 3: Leap year
-----------------------------------------------------
Expected: 1900 -> 0, 2000 -> 1, 2024 -> 1, 2023 -> 0

#include <stdio.h>

int is_leap(int year) {
    if (year % 4 == 0) {
        return 1;
    } else if (year % 100 == 0) {
        return 0;
    } else if (year % 400 == 0) {
        return 1;
    } else {
        return 0;
    }
}

int main(void) {
    printf("%d\n", is_leap(1900));
    printf("%d\n", is_leap(2000));
    return 0;
}

=====================================================
ANSWER KEY (instructor only)
=====================================================

PROBLEM 1
Bug: Conditions are in the wrong order. 95 matches (score >= 60)
first, so it returns 'D'. The other branches are never reached.
Fix: Check the highest threshold first (>= 90, then >= 80, then
>= 70, then >= 60).

PROBLEM 2
Bugs (two):
  a) "n % 2 = 0" is assignment, not comparison. Use "==". (GCC
     reports an error here, since you cannot assign to an
     expression.)
  b) The function never returns result. Add "return result;".
     Without it, the behavior is undefined.
Fix: if (n % 2 == 0) { ... } and return result; at the end.

PROBLEM 3
Bug: Any year divisible by 4 returns 1 immediately, so 1900 is
wrongly a leap year, and the %400 branch can never run.
Fix: Check %400 first, then %100, then %4. Or use:
  return (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;

PROBLEM 4
Bug: When there is a tie for the biggest value, neither strict ">"
condition is true. It falls to else and returns c (3), which is
wrong for biggest(5, 5, 3).
Fix: Use ">=" in the comparisons.

PROBLEM 5
Bug: doubled is declared void, so it returns nothing and cannot be
used in an expression. It prints instead of returning. The compiler
reports an error for "void value not ignored as it ought to be".
Fix: Change the return type to int and use "return x * 2;". Move
the printing to main if needed.

PROBLEM 6
Bug: discount is uninitialized when is_member is 0, so the result
is garbage (undefined behavior). This is a C-specific trap; there is
no automatic default value.
Fix: Initialize it (double discount = 0.0;) or add an else branch.
