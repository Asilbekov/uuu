Recursion · Chapter 8

1. What recursion means

Recursion solves a task using the same method on a smaller task.

Four students stand in line: A → B → C → D. Each asks the next student to count their part of the line. D, the last student, answers 1. Each waiting student adds themselves:

D: 1 → C: 2 → B: 3 → A: 4

2. Three ingredients

  • Base case: answer directly; no further self-call.
  • Recursive case: call the same function on a smaller input.
  • Progress: every recursive path must reach a base case.

C function excerpt · demonstration inputs: integers 0–7 · printf needs <stdio.h>.

void count_down(int n)
{
    if (n == 0)
        return;

    printf("%i\n", n);
    count_down(n - 1);
}

count_down(3) visits 3 → 2 → 1 → 0. It prints 3, 2, 1 on separate lines; 0 returns without printing.

3. Use a smaller answer: factorial

3! = 3 × 2 × 1 = 6. Recursively: n! = n × (n − 1)!, with 0! = 1.

C function excerpt · demonstration inputs: integers 0–7.

int factorial(int n)
{
    if (n == 0)
        return 1;

    int smaller = factorial(n - 1);
    return n * smaller;
}

The caller waits for the smaller answer, then multiplies by its own n. Returning a value does not print it.

4. Calls wait; returns resume them

The call stack holds unfinished calls. Each stack frame keeps that call’s parameters, local variables and next action. Only the top call executes.

factorial(3): calls go down ↓; answers return up ↑
Call Work waiting Returns
n = 3 3 × smaller answer 6
n = 2 2 × smaller answer 2
n = 1 1 × smaller answer 1
n = 0 Base case 1

At the deepest point, factorial(0) runs. Each return removes one finished frame; its caller resumes. Finally, main receives 6.

5. Order and stopping matter

Move the same print before or after the smaller call
Print position Output for n = 3
Before the call 3, 2, 1
After the call 1, 2, 3

Each number prints on its own line. With count_down( n ) instead of count_down(n - 1), starting at 3 never reaches 0. Unbounded recursion can exhaust stack space.

A loop can also calculate factorial: it keeps a counter and running product instead of waiting recursive calls. Recursion is not automatically faster.

6. Fibonacci: two smaller answers

F(0) = 0; F(1) = 1. Then F( n ) = F(n − 1) + F(n − 2).

0, 1, 1, 2, 3, 5, … so F(4) = 3.

Our recursive version makes 9 calls over time for F(4), calculating F(2) twice. The call tree shows all calls; the stack holds only unfinished calls. The two branches run in sequence.

7. Hanoi: solve a smaller tower

Move three disks from A to C using B. Move one top disk at a time; never put a larger disk on a smaller one.

Three steps, seven individual moves
Step Task Moves
1 Move 2 disks A → B, using C 3
2 Move disk 3 A → C 1
3 Move 2 disks B → C, using A 3

3 + 1 + 3 = 7 moves. Each smaller tower uses the same method. Base case: 0 disks → no moves.

// Adapted from CS50x Week 3 recursion. Use heights 0 to 7.
void draw(int n)
{
    if (n <= 0)

07_fibonacci.c — Fibonacci and repeated work

Return F( n ) using two smaller calls; F(0)=0 and F(1)=1. Separate statements fix the classroom evaluation order.

#include <stdio.h>

// Book Fibonacci example, with F(0) = 0 and F(1) = 1.
// Preconditions for this demonstration: integer n from 0 to 10.
int fibonacci(int n)
{
    if (n == 0)
        return 0;
    if (n == 1)
        return 1;

    int left = fibonacci(n - 1);
    int right = fibonacci(n - 2);
    return left + right;
}

int main(void)
{
    int result = fibonacci(4);
    printf("%i\n", result);
    return 0;
}

Expected output

08_hanoi.c — Tower of Hanoi

Print the legal moves for transferring a tower: smaller tower to spare, largest disk to target, smaller tower to target.

#include <stdio.h>

// Book Exercise 8.5: move a tower from source to target using spare.
// Demo preconditions: n from 0 to 4; three distinct peg labels.
// Initially, all n disks are on source, smallest on top; other pegs are empty.
void hanoi(int n, char source, char spare, char target)
{
    if (n == 0)
        return;

    hanoi(n - 1, source, target, spare);
    printf("Move disk %i: %c -> %c\n", n, source, target);
    hanoi(n - 1, spare, source, target);
}

int main(void)
{
    hanoi(3, 'A', 'B', 'C');
    return 0;
}

Expected output

Move disk 1: A -> C
Move disk 2: A -> B
Move disk 1: C -> B
Move disk 3: A -> C
Move disk 1: B -> A
Move disk 2: B -> C
Move disk 1: A -> C
